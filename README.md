## Folder convention

Based on Anders' guidance in Slack (Sept 2, 2026):

```
NN_Topic/
    class/      # files Anders works with directly during teaching; new subfolders only added if he asks for them
    exercise/   # only gets a subfolder/file when an exercise actually requires creating files
    homework/   # only gets a subfolder when a homework task actually requires files
```

Rules of thumb:
- Don't pre-create exercise/homework content — only add a file or subfolder when a specific exercise or homework task needs one (named `NN._<name>`, matching the exercise numbering from the course material).
- `class/` folders may get more subfolders over time — only add them when asked, one per week of teaching.
- Some class weeks turn into **forked repositories** instead of files in this repo (e.g. exercises done in a fork of a starter repo). Those forks are **not deleted** and are tracked in [`Forked_Repositories.md`](./Forked_Repositories.md) — required for Mandatory II.

Right now the only concrete example is Week 1's exercise 05, so [`01_Docker/exercise/05._Dockerizing_a_Maven_project.md`](./01_Docker/exercise/05._Dockerizing_a_Maven_project.md) is the only exercise file that exists so far — everything else is scaffolded empty (via `.gitkeep`) and filled in as it's actually needed.
